# 🚀 FikriShop - Modern E-Commerce Platform

FikriShop is a premium full-stack e-commerce application designed with a focus on seamless user experience, high-performance architecture, and a modern, minimalist interface. Built for scaling modern online studios and digital marketplaces, it features an interactive customer storefront alongside a comprehensive data-driven administrative dashboard.

---

## ✨ Features

### 🎨 Premium UI/UX Design
- **Glassmorphic Layouts & Bento Grid Design:** Clean, multi-layered layouts using fine borders, background blurs, and modern grid structures for data presentation.
- **Interactive Sliders & Carousels:** Smooth, performance-optimized touch swiping implemented via `Swiper.js`.
- **Consistent Iconography:** Clean vector icon integrations powered by `lucide-react`.

### 🛒 Customer Storefront
- Dynamic single-page client routing.
- Responsive, persistent shopping cart and customized filtering controls.
- Optimized multi-image media carousels for products and seller galleries.

### 📊 Administrative & Seller Dashboard
- **Inventory Matrix Table:** Full-featured data tables built to monitor stock levels, categories, and item statuses instantly.
- **Revenue Analytics & Metrics:** Real-time financial visualizations using responsive interactive charts (`Recharts`) and customizable dashboard components (`Material-UI`).

### 💳 Transaction Layer & Infrastructure
- **Payment Gateway Integration:** Secure, instant order initialization and verification workflows using the `Razorpay SDK`.
- **Database Architecture:** Built on highly-available remote databases hosted via `MongoDB Atlas`.

---

## 🛠 Tech Stack

### Frontend
- **Framework:** React.js
- **Styling:** Tailwind CSS (Custom themes, glassmorphism utilities)
- **UI Components & Charts:** Material-UI (MUI), Recharts
- **Sliders & Swipers:** Swiper.js
- **Icons:** Lucide React

### Backend & Database
- **Runtime:** Node.js
- **Server Framework:** Express.js
- **Database Platform:** MongoDB Atlas (Mongoose ODM)
- **Payments:** Razorpay Web Checkout SDK
